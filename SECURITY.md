# Security

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public issue.

Useful to include: the affected URL or endpoint, steps to reproduce, and the impact you expect.
You will get an acknowledgement, and a fix or an explanation once it has been assessed.

In scope: shieldedscan.xyz, testnet.shieldedscan.xyz, the API at api.shieldedscan.xyz, and this
code. Out of scope: denial-of-service testing, and third-party services the site links to.

Never send a seed phrase, spending key or viewing key — not in a report, not anywhere.
